Security

The PIN keeps people out of the app screen. It does not encrypt your trades: anyone who can open this browser's developer tools or copy its storage can still read them, and the wrong-PIN wait can be reset the same way. For a protected copy, set a password when you export a backup. Forgot the PIN? You'll have to clear app data, which deletes your trades. Export a backup first.

Lock after leaving the app

Export backup

Save all trades, accounts and settings as one JSON file. Send it to Drive, Telegram or Files to keep it safe. Background photos are not included.

With a password the file is encrypted (AES-256). If you forget it, the backup cannot be opened. The password is never saved.

Import backup

Pick a JSON backup from this app (old CSV files still work). You can add the trades to your current ones, or restore everything including settings.
